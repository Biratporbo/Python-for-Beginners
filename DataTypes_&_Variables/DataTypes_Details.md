# Data Types Details (1st to 4th Files)

1st file shows numeric types like int, float, complex, and bool, where numbers are stored in different forms and the type() function checks their categories.

2nd file shows string type, where text is stored in quotes and slicing or repetition is used to access or repeat characters.

3rd file shows sequence types like list, tuple, and range, where data can be stored in ordered collections and accessed by index or slicing.

4th file shows bytes, bytearray, and memoryview, which are used to handle binary-style data and low-level memory representation in Python.


The four files teach the basic Python data types:

- numeric values: int, float, complex, bool
- text values: string
- collections: list, tuple, range
- binary values: bytes, bytearray, memoryview

These are the basic building blocks of Python programming.

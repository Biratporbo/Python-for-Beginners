# Python Basics from test.py

This file explains only the basic Python ideas used in the sample script.

## 1. print()

`print()` is used to display output on the screen.

```python
print("Hello World!")
```

Output:

```python
Hello World!
```

## 2. Comments

Comments are notes in code. Python does not run them.

```python
# This is a single-line comment
```

You can also use a multi-line string as a comment:

```python
'''This is comment method to used'''
```

## 3. input()

`input()` is used to get information from the user.

```python
name = input("What is your name?")
print(name)
```

This will wait for user input and then print it.

## 4. Using input with print

```python
name = input("What is your name?")
print("Hello,", name)
```

This prints a message and the name together.

## 5. Pseudocode

Pseudocode means writing the logic in simple English before coding.

```python
# ask for there name
name = input("How about you?")
# give to answer to the user
print("Hi!")
print(name)
```

## 6. Basic Example from test.py

```python
# At First Print the statment -->
print("Hello World!")

name = input("What is your name?")
print("Hello,")
print(name)
```

## 7. Summary

The basic Python things used here are:

- `print()` to show output
- `input()` to receive user input
- variables to store values
- comments to explain code
- simple messages to interact with the user

## 8. Important Note

Python programs run line by line from top to bottom.

That is why the code order matters:

```python
name = input("Enter your name")
print("Hello, " + name)
```

This means: first read the input, then print the result.
